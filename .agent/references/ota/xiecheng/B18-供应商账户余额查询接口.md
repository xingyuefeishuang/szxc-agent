# 供应商账户余额查询接口

## 基础信息
- **接口名称**：供应商账户余额查询
- **接口地址**：`/SupplierBalanceQuery.do`
- **请求方式**：POST
- **数据格式**：application/json
- **接口描述**：携程主动调用此接口，根据携程供应商id查询供应商账户余额，供应商收到请求后返回准确的商家账户信息，即授信账户余额或预付款账户余额。

---

## 请求参数
### 1. 请求参数示例
```json
{
  "header": {
    "accountId": "xiecheng",
    "serviceName": "SupplierBalanceQuery",
    "requestTime": "2017-01-05 10:00:00",
    "version": "1.0",
    "sign": "374d95774f17c3e354e73f7aaf21b5ec"
  },
  "body": {
    "vendorId": "12345"
  }
}
```

### 2. 请求头 (Headers)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| accountId | string | 是 | 供应商帐号，由携程分配 | xiecheng |
| serviceName | string | 是 | 接口名称: SupplierBalanceQuery | SupplierBalanceQuery |
| requestTime | string | 是 | 请求时间(格式: yyyy-MM-dd HH:mm:ss) | 2017-01-05 10:00:00 |
| version | string | 是 | 版本号, 1.0 | 1.0 |
| sign | string | 是 | 签名 | 374d95774f17c3e354e73f7aaf21b5ec |

### 3. 请求体 (Request Body)

**注意：请求体 body 节点在传输时需要 AES 加密。**

#### Body 结构 (加密前)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| vendorId | string | 是 | 供应商ID，即携程系统中的供应商ld，可联系携程业务同事获取。如开发者为系统商，此ID需与您系统中的供应商建立一一对应的关系，以保证查询结果的准确性。 | 12345 |

---

## 响应参数
### 1. 响应参数示例
```json
{
  "header": {
    "resultCode": "0000",
    "resultMessage": "操作成功"
  },
  "body": {
    "vendorId": "12345",
    "prepaidAccountBalance": "1000.22",
    "prepaidAccountBalanceCurrency": "CNY",
    "creditAccountBalance": "1000.22",
    "creditAccountBalanceCurrency": "CNY"
  }
}
```

### 2. 响应头 (Response Headers)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| resultCode | string | 是 | 处理结果返回码, 参考: [供应商接口返回码](#section/供应商接口返回码) | 0000 |
| resultMessage | string | 是 | 处理结果返回信息。若返回结果为失败，需在此字段内明确描述失败原因。参考: [供应商接口返回码](#section/供应商接口返回码) | 操作成功 |

### 3. 响应体 (Response Body)

**注意：响应体 body 节点在传输时需要 AES 加密。**

#### Body 结构 (加密前)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| vendorId | string | 是 | 供应商ID | 12345 |
| prepaidAccountBalance | number | 否 | 供应商订单号当前预付款账户余额，若该供应商存在预付款账户，此节点必填；非预付款商家此节点不填 | 1000.22 |
| prepaidAccountBalanceCurrency | string | 否 | 当前预付款账户余额币种，若prepaidAccountBalance有值，此字段必填，目前支持：CNY-人民币 | CNY |
| creditAccountBalance | number | 否 | 当前授信账户余额，若该供应商存在授信账户，此节点必填；非授信商家此节点不填 | 1000.22 |
| creditAccountBalanceCurrency | string | 否 | 当前授信账户余额币种，若creditAccountBalance有值，此字段必填，目前支持：CNY-人民币 | CNY |
