# 订单退款接口

## 基础信息
- **接口名称**：订单退款
- **接口地址**：`/RefundOrder.do`
- **请求方式**：POST
- **数据格式**：application/json
- **接口描述**：退款接口与订单取消逻辑并无关联，是纯粹的退钱操作，仅作为供应商与客人协商的退款信息传递接口，在退款发起时必须验证退款金额小于等于可退金额。
  <p style='color: red'>供应商接口返回码：务必优先匹配携程提供的标准错误码，并返回真实的失败原因（重要）。</p>

---

## 请求参数
### 1. 请求参数示例
```json
{
  "header": {
    "accountId": "xiecheng",
    "serviceName": "RefundOrder",
    "requestTime": "2017-01-05 10:00:00",
    "version": "1.0",
    "sign": "374d95774f17c3e354e73f7aaf21b5ec"
  },
  "body": {
    "sequenceId": "2017-10-10abcd95774f17c3e354e73f7aaf21b5ec",
    "otaOrderId": "123456",
    "supplierOrderId": "100001",
    "lastConfirmTime": "2017-01-05 10:00:00",
    "totalAmount": 100,
    "totalAmountCurrency": "CNY",
    "items": [
      {
        "itemId": "123456",
        "PLU": "test-plu-1",
        "amount": 100,
        "amountCurrency": "CNY"
      }
    ]
  }
}
```

### 2. 请求头 (Headers)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| accountId | string | 是 | 供应商帐号，由携程分配 | xiecheng |
| serviceName | string | 是 | 接口名称: RefundOrder | RefundOrder |
| requestTime | string | 是 | 请求时间(格式: yyyy-MM-dd HH:mm:ss) | 2017-01-05 10:00:00 |
| version | string | 是 | 版本号, 1.0 | 1.0 |
| sign | string | 是 | 签名 | 374d95774f17c3e354e73f7aaf21b5ec |

### 3. 请求体 (Request Body)

**注意：请求体 body 节点在传输时需要 AES 加密。**

#### Body 结构 (加密前)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| sequenceId | string | 是 | 携程处理批次流水号。格式为处理日期（yyyyMMdd）+32位去分隔符的Guid | 2017-10-10abcd95774f17c3e354e73f7aaf21b5ec |
| otaOrderId | string | 是 | 携程订单号 | 123456 |
| supplierOrderId | string | 是 | 供应商订单号 | 100001 |
| lastConfirmTime | string | 否 | 供应商最晚确认时间，格式：“yyyy-MM-dd HH:mm:ss”。该时间为北京时区的时间，当不为空时如超过该时间后携程将会进行结果的确认处理（订单会被自动退款） | 2017-01-05 10:00:00 |
| totalAmount | number | 是 | 退款总金额 | 100 |
| totalAmountCurrency | string | 是 | 退款总金额单位（货币标准符号） 如：CNY表示人民币 | CNY |
| items | array | 否 | 订单项节点 (见 RefundOrderItems 数组定义) | (见 RefundOrderItems 定义) |

#### RefundOrderItems (订单项) 对象定义

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| itemId | string | 否 | 订单项编号 | 123456 |
| PLU | string | 否 | 供应商产品最小单位，  如供应商产品的资源编号 | test-plu-1 |
| amount | number | 否 | 退款金额 | 100 |
| amountCurrency | string | 否 | 退款金额单位（货币标准符号） 如：CNY表示人民币 | CNY |

## 响应结果
### 1. 响应结果示例
```json
{
  "header": {
    "resultCode": "0000",
    "resultMessage": "退款成功"
  },
  "body": {
    "supplierConfirmType": 1
  }
}
```

### 2. 响应头 (Response Header)

| 参数名称 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| resultCode | string | 处理结果返回码, 参考: [供应商接口返回码](#section/供应商接口返回码) | 0000 |
| resultMessage | string | 处理结果返回信息。若返回结果为失败，需在此字段内明确描述失败原因。参考: [供应商接口返回码](#section/供应商接口返回码) | 退款成功 |

### 3. 响应体 (Response Body)

**注意：响应体 body 节点在传输时需要 AES 加密。**

#### Body 结构 (加密前)

| 参数名称 | 类型 | 必填 | 说明                                           | 示例值 |
| :--- | :--- | :--- |:---------------------------------------------| :--- |
| supplierConfirmType | integer | 是 | 供应商确认类型：1.退款已确认（同步返回确认结果）；2.退款待确认（需异步返回确认结果） | 1 |
