# 订单新订确认接口

## 基础信息
- **接口名称**：订单新订确认
- **接口地址**：`/CreateOrderConfirm.do`
- **请求方式**：POST
- **数据格式**：application/json
- **接口描述**：当订单在新订提交后供应商需异步确认进行操作（接受、拒绝），可通过此接口回传供应商的最终确认结果给到携程。不接受同批次的新订推送多次不同操作（接受、拒绝）结果给到携程。`回调结果以携程返回成功为准，如果失败请重新推送回调信息（重要）`

| itemId | string | 否 | 订单项编号，如果按资源单位来匹配凭证则必返回值 | 123456 |
| voucherId | string | 是 | 凭证编号，isCredentialVouchers=1必填，需保证订单内唯一，会用于核销和退订 | 123456 |
| voucherType | integer | 是 | 凭证形式，1:普通凭证（凭身份证/手机号等使用）；2:数字码；3:二维码图片（根据供应商返回的原始字符串voucherData生成二维码图片）；4:凭证图片（根据供应商返回的图片数据流voucherData生成凭证图片）；5:PDF确认单（根据供应商返回的文件数据流voucherData生成PDF确认单）；6:凭证链接（根据供应商返回调原始凭证链接voucherData生成短链接）；7:条形码128格式（根据供应商返回voucherData，生成条形码128格式的图片凭证）；8:条形码417格式（根据供应商返回voucherData，生成条形码417格式的图片凭证） | 1 |
