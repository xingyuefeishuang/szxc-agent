# 预下单支付接口

## 基础信息
- **接口名称**：预下单支付
- **接口地址**：`/PayPreOrder.do`
- **请求方式**：POST
- **数据格式**：application/json
- **接口描述**：
  1. 携程调用此接口向供应商支付预下单创建的订单。若供应商接入预下单接口，此接口必接。
  2. 供应商在收到携程的支付请求时，需先判断同批次的携程订单号在供应商系统中是否存在且已支付成功，若存在且已支付成功，直接返回支付成功的下单结果；若不存在，进行支付操作并返回结果；（即支持幂等）
  <p style='color: red'>支付确认的sequenceId请与收到的PayPreOrder接口传递的sequenceId保持一致</p> 
  <p style='color: red'>供应商接口返回码：务必优先匹配携程提供的标准错误码，并返回真实的失败原因（重要）。</p>
