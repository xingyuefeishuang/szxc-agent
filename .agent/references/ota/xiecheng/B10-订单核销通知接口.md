# 订单核销通知接口

## 基础信息
- **接口名称**：订单核销通知
- **接口地址**：`/OrderConsumedNotice.do`
- **请求方式**：POST
- **数据格式**：application/json
- **接口描述**：当订单在新订确认后，供应商可将客人出行后的使用情况或归还物品等信息调用该接口将对应的最终结果同步给携程系统，例如门票的入园使用结果、Wi-Fi等租赁类还件操作。
  `回调结果以携程返回成功为准，如果失败请重新推送回调信息（重要）。`

---

### 1. 请求参数示例
```json
{
  "header": {
    "accountId": "xiecheng",
    "serviceName": "OrderConsumedNotice",
    "requestTime": "2017-01-05 10:00:00",
    "version": "1.0",
    "sign": "374d95774f17c3e354e73f7aaf21b5ec"
  },
  "body": {
    "sequenceId": "2017-10-10abcd95774f17c3e354e73f7aaf21b5ec",
    "otaOrderId": "123456",
    "supplierOrderId": "100001",
    "items": [
      {
        "itemId": "123456",
        "useStartDate": "2017-02-04",
        "useEndDate": "2017-02-04",
        "quantity": 1,
        "useQuantity": 1,
        "passengers": [
          {
            "passengerId": "123456"
          }
        ],
        "vouchers": [
          {
            "voucherId": "123456"
          }
        ],
        "remark": "备注信息",
        "discount": {
          "policyList": [
            {
              "date": "2018-01-16",
              "quantity": 1
            }
          ]
        },

      }
    ]
  }
}
```

### 2. 请求头 (Headers)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| accountId | string | 是 | 供应商帐号，由携程分配 | xiecheng |
| serviceName | string | 是 | 接口名称: OrderConsumedNotice | OrderConsumedNotice |
| requestTime | string | 是 | 请求时间(格式: yyyy-MM-dd HH:mm:ss) | 2017-01-05 10:00:00 |
| version | string | 是 | 版本号, 1.0 | 1.0 |
| sign | string | 是 | 签名 | 374d95774f17c3e354e73f7aaf21b5ec |

### 3. 请求体 (Request Body)

**注意：请求体 body 节点在传输时需要 AES 加密。**

#### Body 结构 (加密前)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| sequenceId | string | 是 | 供应商处理批次流水号，格式为处理日期（yyyyMMdd）+32位去分隔符的Guid | 2017-10-10abcd95774f17c3e354e73f7aaf21b5ec |
| otaOrderId | string | 是 | 携程订单号 | 123456 |
| supplierOrderId | string | 是 | 供应商订单号 | 100001 |
| items | array | 是 | 订单项节点 (见 OrderConsumedNoticeItems 数组定义) | (见 OrderConsumedNoticeItems 定义) |

#### OrderConsumedNoticeItems (订单项) 对象定义

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| itemId | string | 是 | 订单项编号 | 123456 |
| useStartDate | string | 是 | 实际使用开始日期，格式：“yyyy-MM-dd” | 2017-02-04 |
| useEndDate | string | 是 | 实际使用结束日期，格式：“yyyy-MM-dd”，  如只有一天将与useStartDate值相同 | 2017-02-04 |
| quantity | integer | 是 | 订单总份数 | 1 |
| useQuantity | integer | 是 | 订单已核销总份数。订单核销总份数，如该笔订单共购买三张，游客第一次核销2张，则传值2，第二次又核销一张，则传值3 | 1 |
| passengers | array | 否 | 已核销的份数所对应的出行人，一张一人该节点必填，**注：** 1、传值代表已核销不可再次使用；2、若isCredentialVouchers=1，凭证所绑定的全部出行人均核销后，携程会置该绑定的凭证为已核销状态 | (见 Passengers 定义) |
| vouchers | array | 否 | 已核销的份数所对应的凭证，有已核销凭证时必填，**注：** 1、传值代表此凭证已核销不可再次使用，若该凭证为多次核销场景，请在最后一次核销时传值；2、若isCredentialVouchers=1，出行人所绑定的全部凭证均核销后，携程会置该绑定的出行人为已核销状态 | (见 Vouchers 定义) |
| remark | string | 否 | 备注信息 | 备注信息 |
| discount | object | 否 | 优惠信息节点| (见 Discount 定义) |
| lostAmount | number | 否 | 实际损失金额 | 500 |
| lostAmountCurrency | string | 否 | 实际损失金额单位（货币标准符号），暂只支持人民币，如：CNY表示人民币 | CNY |

#### Passengers (出行人) 对象定义

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| passengerId | string | 是 | 出行人编号 | 123456 |

#### Vouchers (凭证) 对象定义

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| voucherId | string | 是 | 凭证编号 | 123456 |

#### Discount (优惠信息) 对象定义

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| policyList | array | 否 | 优惠策略集合节点，仅供wifi租赁使用（/台/天） | (见 PolicyList 定义) |

#### PolicyList (优惠策略) 对象定义

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| date | string | 否 | 优惠日期, 格式：“yyyy-MM-dd” | 2018-01-16 |
| quantity | integer | 否 | 优惠数量 | 1 |
