# 预下单创建接口

## 基础信息
- **接口名称**：预下单创建
- **接口地址**：`/CreatePreOrder.do`
- **请求方式**：POST
- **数据格式**：application/json
- **接口描述**：在客人下单时，携程向供应商提交下单信息请求预下单，供应商收到请求后验证订单信息，生成订单号并锁定库存，等待后续携程的预下单支付消息。
  供应商在收到携程的预下单请求时，需先判断同批次的携程订单号在供应商系统中是否存在且已预下单成功，若存在且已预下单成功，直接返回预下单成功结果；若不存在，进行预下单操作并返回结果；（即支持幂等）
  注： 1、推荐接入此接口，此接口接入后，订单验证、订单新订接口均无需重复接入； 2、若需要校验订单信息、订单价格，均请在此接口中进行； 3、因涉及用户下单实时响应，接口性能要求较高，最晚需在8s内返回结果；

  <p style='color: red'>供应商接口返回码：务必优先匹配携程提供的标准错误码，并返回真实的失败原因（重要）。</p>

    "resultCode": "0000",
    "resultMessage": "预下单创建成功"
  },

    "otaOrderId": "123456",
    "supplierOrderId": "100001",
    "items": [
      {
        "PLU": "test-plu-1",

          {
            "useDate": "2017-02-04",
            "quantity": 1
          }
        ]
      }
    ]
  }
}
```
