# 订单修改接口

## 基础信息
- **接口名称**：订单修改
- **接口地址**：`/EditOrder.do`
- **请求方式**：POST
- **数据格式**：application/json
- **接口描述**：当客人需要修改订单信息，需要提供该接口。目前仅支持修改出行日期。
  <p style='color: red'>供应商接口返回码：务必优先匹配携程提供的标准错误码，并返回真实的失败原因（重要）。</p>

---

## 请求参数
### 1. 请求参数示例
```json
{
  "header": {
    "accountId": "xiecheng",
    "serviceName": "EditOrder",
    "requestTime": "2017-01-05 10:00:00",
    "version": "1.0",
    "sign": "374d95774f17c3e354e73f7aaf21b5ec"
  },
  "body": {
    "sequenceId": "2017-10-10abcd95774f17c3e354e73f7aaf21b5ec",
    "otaOrderId": "123456",
    "supplierOrderId": "100001",
    "items": [
      {
        "itemId": "123456",
        "originUseStartDate": "2017-02-04",
        "targetUseStartDate": "2017-02-04",
        "originUseEndDate": "2017-02-04",
        "targetUseEndDate": "2017-02-04"
      }
    ]
  }
}
```

### 2. 请求头 (Headers)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| accountId | string | 是 | 供应商帐号，由携程分配 | xiecheng |
| serviceName | string | 是 | 接口名称: EditOrder | EditOrder |
| requestTime | string | 是 | 请求时间(格式: yyyy-MM-dd HH:mm:ss) | 2017-01-05 10:00:00 |
| version | string | 是 | 版本号, 1.0 | 1.0 |
| sign | string | 是 | 签名 | 374d95774f17c3e354e73f7aaf21b5ec |

### 3. 请求体 (Request Body)

**注意：请求体 body 节点在传输时需要 AES 加密。**

#### Body 结构 (加密前)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| sequenceId | string | 是 | 携程处理批次流水号。格式为处理日期（yyyyMMdd）+32位去分隔符的Guid | 2017-10-10abcd95774f17c3e354e73f7aaf21b5ec |
| otaOrderId | string | 是 | 携程订单号 | 123456 |
| supplierOrderId | string | 是 | 供应商订单号 | 100001 |
| items | array | 是 | 订单项节点 (见 EditOrderItems 数组定义) | (见 EditOrderItems 定义) |

#### EditOrderItems (订单项) 对象定义

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| itemId | string | 是 | 订单项编号 | 123456 |
| originUseStartDate | string | 是 | 原始使用开始日期，格式：“yyyy-MM-dd” | 2017-02-04 |
| targetUseStartDate | string | 是 | 修改后开始使用日期，格式：“yyyy-MM-dd” | 2017-02-04 |
| originUseEndDate | string | 是 | 原始使用结束日期，格式：“yyyy-MM-dd” | 2017-02-04 |
| targetUseEndDate | string | 是 | 修改后使用结束日期，格式：“yyyy-MM-dd” | 2017-02-04 |

## 响应结果
### 1. 响应结果示例
```json
{
  "header": {
    "resultCode": "0000",
    "resultMessage": "操作成功"
  },
  "body": {
    "supplierConfirmType": 1,
    "items": [
      {
        "itemId": "123456"
      }
    ]
  }
}
```

### 2. 响应头 (Response Header)

| 参数名称 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| resultCode | string | 处理结果返回码, 参考: [供应商接口返回码](#section/供应商接口返回码) | 0000 |
| resultMessage | string | 处理结果返回信息。若返回结果为失败，需在此字段内明确描述失败原因。参考: [供应商接口返回码](#section/供应商接口返回码) | 操作成功 |

### 3. 响应体 (Response Body)

**注意：响应体 body 节点在传输时需要 AES 加密。**

#### Body 结构 (加密前)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| supplierConfirmType | integer | 是 | 供应商确认类型：1. 修改已确认；2. 修改待确认 | 1 |
| items | array | 否 | 订单项节点 (见 EditOrderResponseItems 数组定义) | (见 EditOrderResponseItems 定义) |

#### EditOrderResponseItems (订单项) 对象定义

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| itemId | string | 是 | 订单项编号 | 123456 |
