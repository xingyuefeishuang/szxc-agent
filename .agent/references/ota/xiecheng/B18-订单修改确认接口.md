# 订单修改确认接口

## 基础信息
- **接口名称**：订单修改确认
- **接口地址**：`/EditOrderConfirm.do`
- **请求方式**：POST
- **数据格式**：application/json
- **接口描述**：当订单在修改提交后供应商需异步确认进行操作（接受、拒绝），可通过此接口回传供应商的最终确认结果给到携程。不接受同批次的修改推送多次不同操作（接受、拒绝）结果给到携程。

---

## 请求参数
### 1. 请求参数示例
```json
{
  "header": {
    "accountId": "xiecheng",
    "serviceName": "EditOrderConfirm",
    "requestTime": "2017-01-05 10:00:00",
    "version": "1.0",
    "sign": "374d95774f17c3e354e73f7aaf21b5ec"
  },
  "body": {
    "sequenceId": "2017-10-10abcd95774f17c3e354e73f7aaf21b5ec",
    "otaOrderId": "123456",
    "supplierOrderId": "100001",
    "confirmResultCode": "0000",
    "confirmResultMessage": "确认成功",
    "items": [
      {
        "itemId": "123456"
      }
    ]
  }
}
```

### 2. 请求头 (Headers)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| accountId | string | 是 | 供应商帐号，由携程分配 | xiecheng |
| serviceName | string | 是 | 接口名称: EditOrderConfirm | EditOrderConfirm |
| requestTime | string | 是 | 请求时间(格式: yyyy-MM-dd HH:mm:ss) | 2017-01-05 10:00:00 |
| version | string | 是 | 版本号, 1.0 | 1.0 |
| sign | string | 是 | 签名 | 374d95774f17c3e354e73f7aaf21b5ec |

### 3. 请求体 (Request Body)

**注意：请求体 body 节点在传输时需要 AES 加密。**

#### Body 结构 (加密前)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| sequenceId | string | 是 | 供应商处理批次流水号。格式为处理日期（yyyyMMdd）+32位去分隔符的Guid | 2017-10-10abcd95774f17c3e354e73f7aaf21b5ec |
| otaOrderId | string | 是 | 携程订单号 | 123456 |
| supplierOrderId | string | 是 | 供应商订单号 | 100001 |
| confirmResultCode | string | 是 | 确认结果返回码, 参考: [供应商接口返回码](#section/供应商接口返回码) 如：0000表示成功 | 0000 |
| confirmResultMessage | string | 是 | 确认结果信息：确认成功；确认失败+具体原因, 参考: [供应商接口返回码](#section/供应商接口返回码) | 0000 |
| items | array | 是 | 订单项节点 (见 EditOrderConfirmRequestItems 数组定义) | (见 EditOrderConfirmRequestItems 定义) |

#### EditOrderConfirmRequestItems (订单项) 对象定义

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| itemId | string | 是 | 订单项编号 | 123456 |

## 响应参数
### 1. 响应参数示例
```json
{
  "header": {
    "resultCode": "0000",
    "resultMessage": "操作成功"
  }
}
```

### 2. 响应头 (Response Headers)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| resultCode | string | 是 | 处理结果返回码, 参考: [携程接口返回码](#section/携程接口返回码) | 0000 |
| resultMessage | string | 是 | 处理结果返回信息，参考: [携程接口返回码](#section/携程接口返回码) | 操作成功 |
