# 订单验证接口

## 基础信息
- **接口名称**：订单验证
- **接口地址**：`/VerifyOrder.do`
- **请求方式**：POST
- **数据格式**：application/json
- **接口描述**：下单验证接口在客人下单时提前将下单信息提交给供应商系统进行校验，及时告知客人是否可以预定成功，有助于提高订单预定成功率和提升客人预定体验。
  <p style='color: red'>供应商接口返回码：务必优先匹配携程提供的标准错误码，并返回真实的失败原因（重要）。</p>

---

## 响应结果
### 1. 响应结果示例
```json
{
  "header": {
    "resultCode": "0000",
    "resultMessage": "验证成功"
  },
  "body": {
    "items": [
      {
        "PLU": "test-plu-1",
        "inventorys": [
          {
            "useDate": "2017-02-04",
            "quantity": 0
          }
        ]
      }
    ]
  }
}
```

### 2. 响应头 (Response Header)

| 参数名称 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| resultCode | string | 处理结果返回码 | 0000 |
| resultMessage | string | 处理结果返回信息。若返回结果为失败，需在此字段内明确描述失败原因。 | 验证成功 |

### 3. 响应体 (Response Body)

**注意：响应体 body 节点在传输时需要 AES 加密。**

#### Body 结构 (加密前)

| 参数名称 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| items | array | 订单项节点 | (见 VerifyResponseOrderItems 数组定义) |

#### VerifyResponseOrderItems (订单项) 对象定义

| 参数名称 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| PLU | string | 供应商产品最小单位 (如供应商产品的资源编号) | test-plu-1 |
| inventorys | array | 剩余库存数量节点。<br>`注：日期级别库存的产品在库存不足时需返回使用日期中的实际库存数量` | (见 Inventory 数组定义) |

#### Inventory (库存) 对象定义

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| useDate | string | 是 | 使用日期，格式：“yyyy-MM-dd” | 2017-02-04 |
| quantity | integer | 是 | 使用日期对应的剩余库存数量 | 0 |
