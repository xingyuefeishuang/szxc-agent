# 订单出行通知接口

## 基础信息
- **接口名称**：订单出行通知
- **接口地址**：`/OrderTravelNotice.do`
- **请求方式**：POST
- **数据格式**：application/json
- **接口描述**：当订单在新订确认后，供应商可将行前和行中需通知给客人的信息（如出行确认单、司导信息、行程信息），以及在游客取物品（如Wi-Fi）或供应商邮寄物品给客人后均可调用该接口将对应的信息给到携程系统。

---

### 2. 请求头 (Headers)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| accountId | string | 是 | 供应商帐号，由携程分配 | xiecheng |
| serviceName | string | 是 | 接口名称: OrderTravelNotice | OrderTravelNotice |
| requestTime | string | 是 | 请求时间(格式: yyyy-MM-dd HH:mm:ss) | 2017-01-05 10:00:00 |
| version | string | 是 | 版本号, 1.0 | 1.0 |
| sign | string | 是 | 签名 | 374d95774f17c3e354e73f7aaf21b5ec |

### 3. 请求体 (Request Body)

**注意：请求体 body 节点在传输时需要 AES 加密。**

#### Body 结构 (加密前)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| sequenceId | string | 是 | 供应商处理批次流水号，格式为处理日期（yyyyMMdd）+32位去分隔符的Guid | 2017-10-10abcd95774f17c3e354e73f7aaf21b5ec |
| otaOrderId | string | 是 | 携程订单号 | 123456 |
| supplierOrderId | string | 是 | 供应商订单号 | 100001 |
| vouchers | array | 否 | 凭证集合节点 (见 Vouchers 数组定义) | (见 Vouchers 定义) |
| orderExtendMessage | string | 否 | 订单附加信息，  若需要向客人提供订单维度的凭证附加说明信息时，可使用此字段。如使用的注意事项/入园须知等等。 | 订单附加信息 |
| items | array | 是 | 订单项节点 (见 OrderTravelNoticeItems 数组定义) | (见 OrderTravelNoticeItems 定义) |

#### Vouchers (凭证) 对象定义
*(定义同其他接口一致，参考下方或通用定义)*

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| itemId | string | 否 | 订单项编号，如果按资源单位来匹配凭证则必返回值 | 123456 |
| voucherId | string | 是 | 凭证编号，isCredentialVouchers=1必填，需保证订单内唯一，会用于核销和退订 | 123456 |
| voucherType | integer | 是 | 凭证形式，1:普通凭证（凭身份证/手机号等使用）；2:数字码；3:二维码图片；4:凭证图片；5:PDF确认单；6:凭证链接；7:条形码128格式；8:条形码417格式 | 1 |
| voucherCode | string | 否 | 凭证数字码 | 123456 |
| voucherData | string | 否 | 凭证数据源 | (见文档) |
| voucherSeatInfo | string | 否 | 凭证座位信息 | 15排09座 |

#### OrderTravelNoticeItems (订单项) 对象定义

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| itemId | string | 是 | 订单项编号 | 123456 |
| isCredentialVouchers | integer | 是 | 是否出行人与凭证有关联关系，  1:相关 0:不相关 | 0 |
| passengerVouchers | array | 否 | 出行人凭证关系节点，isCredentialVouchers=1必填 | (见 PassengerVouchers 定义) |
| remark | string | 否 | 备注信息 | 备注信息 |
| expressDelivery | object | 否 | 配送信息节点 (见 ExpressDelivery 对象定义) | (见 ExpressDelivery 定义) |
| travelInformations | array | 否 | 出行信息节点，注：当司导、时间、地点等信息需通知给客人时可返回值，如多次通知会覆盖之前的信息，全部的出行信息（名称+内容）需小于500字符 | (见 TravelInformations 定义) |

#### PassengerVouchers (出行人凭证关系) 对象定义

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| passengerId | string | 是 | 出行人编号 | 123456 |
| voucherId | string | 是 | 凭证编号 | 123456 |

#### ExpressDelivery (配送信息) 对象定义

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |

| trackingNumber | string | 否 | 快递单号 | 1234567890-12354 |
| goodsName | string | 否 | 物品名称，如wifi、发票 | wifi |
| goodsQuantity | string | 否 | 物品数量 | 5 |
| sendMessage | string | 否 | 发货地址和联系方式 | 上海市福泉路99号携程技术大厦 200335 电话021-12345678 |

## 响应结果
### 1. 响应结果示例
```json
{
  "header": {
    "resultCode": "0000",
    "resultMessage": "操作成功"
  }
}
```
### 2. 响应头 (Response Header)

| 参数名称 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| resultCode | string | 处理结果返回码, 参考: [携程接口返回码](#section/携程接口返回码) | 0000 |
| resultMessage | string | 处理结果返回信息，参考: [携程接口返回码](#section/携程接口返回码) | 操作成功 |
