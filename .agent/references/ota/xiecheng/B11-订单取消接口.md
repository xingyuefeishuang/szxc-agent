# 订单取消接口

## 基础信息
- **接口名称**：订单取消
- **接口地址**：`/CancelOrder.do`
- **请求方式**：POST
- **数据格式**：application/json
- **接口描述**：提供携程与供应商系统进行订单取消操作的接口，当confirmType=2在取消发起时必须验证取消数量等于可退数量，可退数量小于申请退订数量时请返回取消失败。
  <p style='color: red'>供应商接口返回码：务必优先匹配携程提供的标准错误码，并返回真实的失败原因（重要）。</p>

---

## 请求参数
### 1. 请求参数示例
```json
{
  "header": {
    "accountId": "xiecheng",
    "serviceName": "CancelOrder",
    "requestTime": "2017-01-05 10:00:00",
    "version": "1.0",
    "sign": "374d95774f17c3e354e73f7aaf21b5ec"
  },
  "body": {
    "sequenceId": "2017-10-10abcd95774f17c3e354e73f7aaf21b5ec",
    "otaOrderId": "123456",
    "supplierOrderId": "100001",
    "confirmType": "1",
    "items": [
      {
        "itemId": "123456",
        "PLU": "test-plu-1",
        "lastConfirmTime": "2017-01-05 10:00:00",
        "cancelType": 0,
        "quantity": 1,
        "passengers": [
          {
            "passengerId": "123456"
          }
        ],
        "amount": 100,
        "amountCurrency": "CNY"
      }
    ]
  }
}
```

### 2. 请求头 (Headers)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| accountId | string | 是 | 供应商帐号，由携程分配 | xiecheng |
| serviceName | string | 是 | 接口名称: CancelOrder | CancelOrder |
| requestTime | string | 是 | 请求时间(格式: yyyy-MM-dd HH:mm:ss) | 2017-01-05 10:00:00 |
| version | string | 是 | 版本号, 1.0 | 1.0 |
| sign | string | 是 | 签名 | 374d95774f17c3e354e73f7aaf21b5ec |

### 3. 请求体 (Request Body)

**注意：请求体 body 节点在传输时需要 AES 加密。**

#### Body 结构 (加密前)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| sequenceId | string | 是 | 携程处理批次流水号。格式为处理日期（yyyyMMdd）+32位去分隔符的Guid | 2017-10-10abcd95774f17c3e354e73f7aaf21b5ec |
| otaOrderId | string | 是 | 携程订单号 | 123456 |
| supplierOrderId | string | 是 | 供应商订单号 | 100001 |
| confirmType | integer | 是 | 确认类型。1：仅通知供应商订单操作。如果需要确认订单，供应商应在携程VBK后台操作。接口层面上，供应商返回成功（0000）即可，且该结果不影响订单在携程VBK后台的确认结果；2：供应商系统（同步或异步）确认。携程根据供应商返回结果（成功或失败）或异步通知的结果（确认通过或确认拒绝）进行处理，常规对接均为2。 | 1 |
| items | array | 是 | 订单项节点 (见 CancelOrderItems 数组定义) | (见 CancelOrderItems 定义) |

#### CancelOrderItems (订单项) 对象定义

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| itemId | string | 是 | 订单项编号 | 123456 |
| PLU | string | 是 | 供应商产品最小单位，  如供应商产品的资源编号 | test-plu-1 |
| lastConfirmTime | string | 否 | 供应商最晚确认时间，格式：“yyyy-MM-dd HH:mm:ss”。该时间为北京时区的时间，  仅当confirmType=2，且合同中对客售后服务是由商家提供时，此字段必传（注：若超出此时间订单仍未被确认，携程会自动对客退订） | 2017-01-05 10:00:00 |
| cancelType | integer | 是 | 退订类型，必填，0、全退；1、按份数部分退；2、按出行人部分退；若为全退/按份数退，会传取消份数；若为按出行人退，会传取消份数及取消份数包含的全部出行人 | 0 |
| quantity | integer | 是 | 本次请求取消份数 | 1 |
| passengers | array | 否 | 退订出行人节点，cancelType=2时该节点必传，传取消份数包含的全部出行人 (见 Passengers 定义) | (见 Passengers 定义) |
| amount | number | 否 | 被取消的退款金额。当合同中对客售后服务是由商家提供时，此字段会传值（退款金额为PLU的单位卖价扣除手续费后的金额） | 100 |
| amountCurrency | string | 否 | 被取消的退款金额单位（货币标准符号），如：CNY表示人民币 | CNY |

#### Passengers (出行人) 对象定义

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| passengerId | string | 是 | 出行人编号 | 123456 |

## 响应结果
### 1. 响应结果示例
```json
{
  "header": {
    "resultCode": "0000",
    "resultMessage": "取消成功"
  },
  "body": {
    "supplierConfirmType": 1,
    "items": [
      {
        "itemId": "123456",
        "vouchers": [
          {
            "voucherId": "123456"
          }
        ]
      }
    ]
  }
}
```

### 2. 响应头 (Response Header)

| 参数名称 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| resultCode | string | 处理结果返回码, 参考: [供应商接口返回码](#section/供应商接口返回码) | 0000 |
| resultMessage | string | 处理结果返回信息。若返回结果为失败，需在此字段内明确描述失败原因。参考: [供应商接口返回码](#section/供应商接口返回码) | 取消成功 |

### 3. 响应体 (Response Body)

**注意：响应体 body 节点在传输时需要 AES 加密。**

#### Body 结构 (加密前)

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| supplierConfirmType | integer | 是 | 供应商确认类型：1.取消已确认（当confirmType =1/2时可同步返回确认结果）；2.取消待确认（当confirmType =2时需异步返回确认结果的） | 1 |
| items | array | 否 | 订单项节点 (见 CancelOrderResponseItems 数组定义) | (见 CancelOrderResponseItems 定义) |

#### CancelOrderResponseItems (订单项) 对象定义

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| itemId | string | 是 | 订单项编号 | 123456 |
| vouchers | array | 否 | 已取消的凭证，若订单取消成功且存在被取消的凭证，必填，  注：传值代表此凭证已取消不可使用 (见 Vouchers 定义) | (见 Vouchers 定义) |

#### Vouchers (凭证) 对象定义

| 参数名称 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| voucherId | string | 是 | 凭证编号 | 123456 |
